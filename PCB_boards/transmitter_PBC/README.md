This folder provides the schematic, PCB layout and 3D KiCad models of the Transmitter board.

This board track the button presses that are connected to the SIGNAL screw terminal.
If the button is pressed once it sends a RF signal to the receiver board to turn ON the Relay.
If the button is double pressed it sends a RF signal to the receiver board to turn OFF the Relay.

The realy state is indicated by the LED on the board:
if the LED is Green = Relay ON
if the LED is Red = Relay OFF
