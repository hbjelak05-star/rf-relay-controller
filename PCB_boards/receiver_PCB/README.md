This folder provides the schematic, PCB layout and 3D KiCad models of the receiver board.

The main purpose of this board it to receive RF signals form the transmitter board and forward those messages to the Relay board via the male pin connectors.

It receives a message form the transmitter board and depending on the message comand either turns the relay ON or OFF on the relay PCB board.

The Realy state is indicated by the LED on the board:
if the LED is Green = Relay ON
if the LED is Red = Relay OFF
